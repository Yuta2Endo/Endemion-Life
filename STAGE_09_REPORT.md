# Endemion Life — Stage 09: World Events & Living Narrative

Дата: 2026-11-05. Аудит: [STAGE_09_AUDIT.md](STAGE_09_AUDIT.md), план: [STAGE_09_PLAN.md](STAGE_09_PLAN.md).

**Коротко.** Второй движок событий не писался: выбор года, условия, развилки и отложенные последствия уже есть. Событие года теперь видит пройденное дело и достижение рода. Хроника помнит любое приключение мира, не только шесть помеченных.

Не выкатывалось. Миграций нет, формат сохранения остался 7.

## 1. Что сделано

| Требование | Как |
| --- | --- |
| Событие после дела | Условие `deedAny`. Событие «Слава по дороге», один раз |
| Событие после конкретного дела | Условие `deed`: id и исход, пройдено или провалено |
| Событие после достижения | Условие `achievement`. Событие «Род помнит» на четвёртом поколении, один раз |
| Дело в хронике | Пишется для любого приключения мира. След на край — только у помеченных |
| Выбор, пауза, последствия | Не менялись |
| Дружба игроков | В событие года не входит |

## 2. Решения

- Условие проверяет тот же `isEligible`, что и остальные. Отдельного включения событий нет.
- «Слава по дороге» смотрит на любое пройденное дело, а не на шесть копий по мирам.
- Дружба живёт в таблице `ties`, событие считается из сохранения. Смешивать их нельзя: откат жизни дружбу не отменит, и событие осталось бы после отката.
- Планировщик не добавлялся. Событие по-прежнему выбирается, когда игрок проживает год.
- След на напряжение края остаётся только у дел из `ADVENTURE_MARK`. Хроника пишется для всех: новое приключение попадёт в род без правки таблицы.

- Миграций нет. Новых маршрутов нет.

- Старые сохранения читаются.

## 5. Интерфейс

Отдельного экрана нет. Событие показывается прежней карточкой выбора. Дело видно в хронике рода, как в Stage 08.

## 6. Целостность

- Пока дела нет, условие ложно и событие не приходит.
- У обоих событий `maxOccurrences: 1`. Повтор года событие не вызывает.
- Чужой id приключения условием не считается.
- Запись в хронике по-прежнему одна: id попадает в `seen` сразу после неё.

## 8. Не сделано

- События от дружбы. Дружба не в сохранении.
- Планировщик событий вне хода игрока.
- Свои события на каждое из шести приключений. Условие `deed` для этого готово, контента нет.

## 9. Известные проблемы

- «Слава по дороге» приходит один раз за жизнь, даже если дел было несколько.
- Провал дела событие славы не открывает. Для провала есть условие `deed` с `done: false`, но события на него нет.
- След на край у нового приключения сам не появится: его по-прежнему надо занести в `ADVENTURE_MARK`. В хронику оно попадёт и без этого.
