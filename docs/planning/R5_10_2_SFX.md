## 1. Что добавлено

Короткие синтезированные звуки интерфейса через Web Audio. Это не отдельные
аудиофайлы: эффекты строятся на осцилляторах и шумовых всплесках, поэтому не
добавляют сетевой вес и работают поверх уже загруженных мировых тем.

Звук SFX включается тем же переключателем, что и музыка мира
(`endemion-world-sound`). Если звук выключен, `playSfx` сразу выходит и ничего
не создаёт.

| Событие | Звук |
|---|---|
| Выбор варианта события | `choice` |
| Успешная проверка | `success` |
| Проваленная проверка | `failure` |
| Обычный итог без проверки | `page` |
| Ручной год / «жить до события» | `page` |
| Успешная сделка на рынке | `coin` |
| Открытие уведомлений | `bell` |
| Включение звука | `click` |
| Смерть и открытие итогов жизни | `death` |
| Выбор наследника / семейный совет | `council` |
| Успешное продолжение рода | `success` |

В наборе также есть `reward` — зарезервирован для будущих наград и сезонных
событий.

## 2. Реализация

- `apps/web/src/lib/sfx.ts`:
  - `SFX_NAMES` — десять именованных эффектов;
  - `SFX_PATTERNS` — частоты, задержки, длительности, громкости и шумовые слои;
  - ленивый общий `AudioContext`, master gain и короткие envelope-огибающие;
  - `playSfx(name)` безопасен для SSR/Node, молчит при выключенном звуке и
    глотает ошибки приватного режима или лимита AudioContext.
- `apps/web/src/lib/sfx.test.ts` — проверяет полноту паттернов, положительные
  параметры, длительность не более 1.3 с и безопасный no-op без браузера.
- `event-card.tsx` — звук выбора и автоматический звук итога по результату
  проверки.
- `play-screen.tsx` — звук ручного года, сделки, смерти и успешного наследника.
- `sound-toggle.tsx` — подтверждающий click при включении звука.
- `notifications-bell.tsx` — bell при открытии панели.
- `life-summary.tsx` — death при появлении итогов и council при выборе
  наследника.

Звуки намеренно тихие и короткие: они подтверждают действие, но не спорят с
мировой темой. Автожизнь не издаёт звук на каждый год.

## 4. Ограничения

- Громкость SFX не регулируется отдельно — только общий переключатель звука.
- Нет отдельных настроек на каждый эффект.
- Звук запускается после пользовательского жеста; браузерная политика autoplay
  может задержать первый звук до клика.
- SFX и мировая тема используют разные `AudioContext`; это осознанно, чтобы
  переключение мира не обрывало интерфейсные звуки.
- Реальное прослушивание на Android WebView и в screen-reader сценариях не
  автоматизировано.
