## Срезы

### 03.1 — Наследуемое имущество и реликвии
- Оценка наследства: золото + стоимость дома + стоимость дел.
- Передача фамильного дома старшему совершеннолетнему наследнику по неэгалитарному закону; иначе продажа в золото.
- `InheritanceRecord.assets` и отображение в интерфейсе.
- Реликвии: по одному событию получения на мир, механика утраты, наследование, запрет дублей.
- Additive schema 13 → 14, старые сохранения читаются.

### 03.2 — Непрерывность рода
- Перенос социальной памяти NPC–NPC через наследование с пересчётом id.
- Сохранение тика мира, поселений и фракционного состояния.
- Тест пяти поколений подряд без дублей и потерянных ссылок.
- Проверка, что откат не создаёт второго наследника.

### 03.3 — Агентность наследника и хроника
- Экран выбора наследника: причина первичности, последствия, кому отходит дом, кто опекун.
- Улучшение хроники/архива: фильтры по поколениям, достижения, реликвии, итоги жизни.
- Проверка доступности и клавиатурной навигации на desktop/mobile.
- Explainable AI primary heir: текстовая причина из закона, родства, возраста и достоинств.

### 03.4 — Законы шести миров
- Тесты отличий: первородство, равный раздел, merit, sect claim, civil code, entail.
- Проверка долей, опеки, сословия, meter carry и реликвий.
- Исправление найденных расхождений без смены схемы.

### 03.5 — Баланс, длинная династия, документация
- 5–10 поколений в детерминированном soak-тесте.
- Инфляция: золото, дом, дела, реликвии, доля казны.
- Обновление `docs/stage-03/`, `PROJECT_STATUS.md`, release record.
- Полный прогон game-core, API, shared, web; typecheck/lint/build.
