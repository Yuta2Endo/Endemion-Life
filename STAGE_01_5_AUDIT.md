## 6. Гостевые сессии и безопасность API

| Проверка | Состояние |
| --- | --- |
| Cookie `el_session`: HttpOnly | Да |
| SameSite | `Lax` |
| Secure | Только при `NODE_ENV=production` или `COOKIE_SECURE=true`; в prod-compose сейчас `false` |
| Хранение токена | Только SHA-256, токен 256 бит, формат проверяется регуляркой |
| Ротация токена, срок действия, отзыв | **Нет** (срок только у cookie — 365 дней) |
| CSRF | Изменяющие запросы: только `application/json` и только разрешённый `Origin`. Метод DELETE без тела получит 415 — новые эндпоинты должны быть POST с JSON |
| CORS | Список `CORS_ORIGINS`, `credentials: true` |
| Доверие прокси | `TRUST_PROXY` (по умолчанию `loopback`) |
| Лимит тела | API 16 КБ, Nginx 32 КБ |
| Rate limit | 120 запросов в минуту на IP через Redis. **Без Redis лимит отключается** — для входа и проверки кодов нужен лимит, не зависящий от Redis |
| Доступ к чужим жизням | Все запросы фильтруют по `player_id` из сессии; чужая жизнь — 404. Есть e2e-тест |
| Утечки в логах | Логируются только 5xx со стеком. Cookie и тела запросов не пишутся. Логи — обычный текст Nest, не JSON, без request id и времени выполнения |
| Мониторинг | Только `/api/health`. Оповещений нет. Sentry нет |
