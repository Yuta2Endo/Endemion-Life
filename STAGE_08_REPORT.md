# Endemion Life — Stage 08: Legacy & Long-Term Progression

Дата: 2026-11-05. Аудит: [STAGE_08_AUDIT.md](STAGE_08_AUDIT.md), план: [STAGE_08_PLAN.md](STAGE_08_PLAN.md).

**Коротко.** Род, наследство и достижения уже были со Stage 03, и второй раз их писать было не нужно. Не хватало одного: род не помнил дела героя. Теперь пройденное или проваленное приключение ложится в хронику рода один раз и не стирается при обрезке.

Не выкатывалось. Миграций базы нет, формат сохранения остался 7.

## 1. Что сделано

| Требование | Как |
| --- | --- |
| Память о делах | Вид записи хроники `deed`: id приключения и исход `done` или `failed` |
| Один раз | Пишется там же, где край запоминает след, до отметки в `seen` |
| Не стирается | `deed` в списке записей, которые хроника хранит при обрезке |
| Текст | Собирается при показе из названия приключения. В сохранении готового текста нет |
| Род, наследство, достижения | Не менялись |

## 2. Решения

- Новый движок наследия не заводился. Stage 03 уже ведёт поколения, шесть законов наследства, 30 достижений и итог жизни.
- Запись не хранит название: его даёт контент мира при показе. Смена текста приключения не ломает старые записи.
- Провал тоже пишется. Род помнит и неудачу.
- Наследник получает эти записи вместе с остальной хроникой, как раньше.

## 4. База и API

- Миграций нет.
- Формат сохранения не вырос. Новых маршрутов нет.
- Старые сохранения читаются: записей `deed` в них нет, разбор их не требует.

## 5. Интерфейс

Отдельного экрана нет. Запись видна в хронике рода на вкладке «Род» — там же, где остальные дела семьи. Текст на двух языках.

## 6. Целостность

- Повтор года не пишет вторую запись: след уже в `seen`.
- Обрезка хроники до 340 записей такие записи не трогает.
- Неизвестный id приключения показывает имя человека и ничего не выдумывает.
- Наследство и его защита от повтора не менялись.

## 7. Тесты

Запуск 2026-11-05, Windows, pnpm 12.16.1.

| Команда | Результат |
| --- | --- |
| `pnpm --filter @endemion/game-core test` | 276 из 276 (15 файлов) |
| `pnpm lint` | без ошибок |
| `pnpm build` | собрано |

Новые проверки легли в прежний тест края: одна запись на дело, без второй на следующий год, провал пишется как `failed`. Отдельно гонялся набор рода Stage 03 — зелёный.

Полные `pnpm test:api` и `pnpm test:e2e` не гонялись: маршруты и страницы не менялись.

## 8. Не сделано

- Цепочки достижений поверх существующих 30. Для них нет нового условия, которого не закрывали бы текущие.
- Отдельный экран «наследие». Хроника уже показывает дела.
- Влияние одного игрока на мир другого. Мир по-прежнему свой у каждой жизни.

## 9. Известные проблемы

- В хронике нет имени приключения, если его убрали из контента мира: останется имя человека.
- Дело пишется только для шести приключений, чей след знает край. Новое приключение без строки в `ADVENTURE_MARK` в хронику не попадёт.
