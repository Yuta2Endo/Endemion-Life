# Endemion Life — Stage 05: RPG Adventure Engine

Дата: 2026-11-05. Аудит: [STAGE_05_AUDIT.md](STAGE_05_AUDIT.md), план: [STAGE_05_PLAN.md](STAGE_05_PLAN.md).

**Коротко.** В жизни появилась дорога: места открываются с годами, в каждом из шести миров есть своё приключение из трёх шагов. Игрок выбирает только вариант. Исход, награду и переход считает сервер. Награду шага нельзя получить дважды. Формат сохранения 6.

Не выкатывалось. Прод, GitHub Actions и миграции базы не менялись.

## 1. Что сделано

| Требование | Как |
| --- | --- |
| Приключения в той же жизни | Поле `state.adventure`, отдельных таблиц нет |
| Места | 2 на мир, открываются раз в год из отдельного потока генератора |
| Приключения | 1 на мир, 3 шага, предпосылки по возрасту и месту |
| Столкновения | Существующие проверки `StatCheck`. Второй боевой системы нет |
| Прогрессия | Существующие эффекты: опыт, золото, навык, репутация, фракция, способность |
| Награда один раз | Шаг меняется до эффектов; повтор `actionId` возвращает прежний ответ; завершённое не начинается снова |
| Задания Системы | Не тронуты. Это по-прежнему одно задание Арденвейла со сроком |
| Интерфейс | Вкладка досье «Путь»: места, приключения, шаг, награды, сдача |

## 2. Решения

- Приключение лежит в сохранении, как хозяйство и задание: одна жизнь, один откат, один снимок.
- Броски приключения идут из потока `seed::adventure::rngState`. Основной генератор жизнь не тратит.
- Действие `{ type: "venture" }` идёт через прежний `POST /api/lives/:id/actions`: та же транзакция, `actionId`, `expectedVersion`.
- `adventureId` — начать, `choiceId` — шаг, пустое — сдаться. Сдача кладёт приключение в проваленные без награды.
- Наследник приключения не получает: открытые места — личный опыт.
- id мест и приключений — `мир.имя`. Схема запросов принимает точку только в этом действии.

## 5. База и API

- Миграций нет. Формат живёт в `state`.
- Формат сохранения 6. `migrateV5` добавляет пустое приключение и ничего не удаляет. `rngState` не меняется.
- `parseSave` принимает только места и приключения мира этой жизни, одно активное, журнал до 32 записей.
- Новое действие — вариант прежнего `gameActionSchema`. Новых маршрутов нет.

## 6. Интерфейс

Вкладка досье «Путь» (RU/EN):

- места: открытые с названием, закрытые — «неизведанное место» и возраст;
- приключения: кнопка «Отправиться» или причина, почему нельзя;
- текущий шаг: варианты, шанс проверки, награда текстом;
- «Отступить»;
- журнал дороги.

На телефоне досье по-прежнему отдельная вкладка. Новых компонентов библиотеки нет: `Panel` и `Button`.

## 8. Совместимость

- Сохранения 1–5 доходят до 6 без потерь. Проверено на фикстурах форматов 3 и 4.
- Задания Системы, рынок, хозяйство и род не менялись по правилам.
- Открытие места сдвигает только свои броски. Два одинаковых прогона дают одни и те же места.

## 9. Не сделано

- Задания с цепочками предпосылок между разными приключениями: поле `requires` есть, контента с ним нет.
- Отдельные задания персонажа (по происхождению, таланту).
- Больше одного приключения на мир.
- Случайные события исследования. Сознательно: план запрещает произвольные повторяющиеся события.
- Повтор полного браузерного прогона на финальной сборке.

## 10. Известные проблемы

- Провал проверки кончает приключение сразу, без второго шанса. Так задумано, но на честном персонаже часть приключений кончается неудачей.
- Награда финала показывается до старта по первому варианту последнего шага. Если игрок выберет другой финал (Девять Рек), награда будет другой.
- Склонение имён в текстах не учитывается, как и в Stage 03–04.
