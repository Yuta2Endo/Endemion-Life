# Endemion Life — Stage 07: план

Основание: [STAGE_07_AUDIT.md](STAGE_07_AUDIT.md). Один срез: связи игроков, визит, страница. Общих приключений нет.

## 1. Таблица `ties`

Миграция только добавляет таблицу.

| Столбец | Смысл |
| --- | --- |
| `player_a`, `player_b` | Пара. `player_a` всегда меньше `player_b` |
| `status` | `pending`, `accepted`, `blocked` |
| `asked_by` | Кто отправил запрос или поставил блок |
| `created_at`, `updated_at` | |

Уникальный ключ `(player_a, player_b)`. Индекс по каждому игроку.

Удаление игрока удаляет его связи.

## 2. Правила

- Имя берётся из `id_display_name`, иначе `id_username`. Без имени действие отклоняется: гость не участвует.
- Запрос: создать `pending`. Повтор своего запроса возвращает ту же связь.
- Встречный запрос, пока первый ждёт, принимает дружбу. Один запрос, не два.
- Согласие может дать только тот, кого спросили.
- Отказ удаляет ожидающий запрос. Друга снять — тоже удаление.
- Блок: `blocked`, автор в `asked_by`. Снять блок может только автор. Заблокированный не видит профиль и не шлёт запрос.
- Себе писать нельзя.

Лимиты: друзей не больше 50, ожидающих входящих не больше 20.

## 3. API

Всё под сессией. Чужое — 404, без сессии — 401.

| Метод | Путь | Что |
| --- | --- | --- |
| GET | `/api/social` | Друзья, входящие, исходящие |
| POST | `/api/social/requests` | `{ playerId }` — запрос |
| POST | `/api/social/requests/:id/accept` | Согласие |
| DELETE | `/api/social/ties/:id` | Отказ, снятие друга или блока |
| POST | `/api/social/block` | `{ playerId }` |
| GET | `/api/social/players?name=` | Поиск по точному имени, до 20 |
| GET | `/api/social/players/:id` | Имя и число жизней. Без сохранения |

Имя в поиске — 3–24 символа, как у Endemion ID.

## 4. Интерфейс

Страница `/social` в текущем виде: поиск, входящие с согласием и отказом, друзья, блок. Ссылка в шапке. Тексты RU/EN.

Чужое сохранение, почта и аватар наружу не отдаются.

## 5. Тесты

`apps/api/test/stage07.e2e-spec.ts`:

- запрос, согласие, отказ;
- встречные запросы становятся одной дружбой;
- повтор запроса не создаёт вторую строку;
- согласие чужого — 404;
- блок скрывает профиль и запрещает запрос;
- без имени — отказ;
- без сессии — 401;
- поиск не возвращает сохранение и почту.

## 6. Границы

Не делаем: общие приключения, общие награды, жалобы, WebSocket, присутствие онлайн, выкладку, правку GitHub Actions.

## 7. Приёмка

- Связь хранится в базе, не в сохранении.
- Пара игроков не заводится дважды.
- Блок закрывает визит и запросы.
- В ответах нет чужого сохранения.
- Старые жизни не меняются.
