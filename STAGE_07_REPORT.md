# Endemion Life — Stage 07: Social World

Дата: 2026-11-05. Аудит: [STAGE_07_AUDIT.md](STAGE_07_AUDIT.md), план: [STAGE_07_PLAN.md](STAGE_07_PLAN.md).

**Коротко.** Игроки могут найти друг друга по имени, отправить запрос, принять его и закрыть связь. Связь живёт отдельно от сохранения: дружба не двигает чужую жизнь. Блок скрывает профиль. Общих приключений нет — жизнь по-прежнему принадлежит одному игроку.

Не выкатывалось. GitHub Actions не менялись.

## 1. Что сделано

| Требование | Как |
| --- | --- |
| Запрос и согласие | `ties`, статусы `pending` и `accepted` |
| Пара один раз | Меньший id всегда в `player_a`, уникальный ключ |
| Встречный запрос | Становится дружбой, вторая строка не создаётся |
| Блок | `blocked`. Автор в `asked_by`, снять может только он |
| Визит | Имя и число жизней. Сохранение, почта и аватар не отдаются |
| Приватность | Заблокированный получает 404 и не может послать запрос |
| Гость | Без имени действие закрыто |
| Общие приключения | Не делались. Два игрока не ходят в одно сохранение |

## 2. Решения

- Связь — строка в базе, не поле сохранения. Откат жизни её не трогает.
- Гонка двух встречных запросов упирается в уникальный ключ: остаётся одна строка.
- Поиск идёт по точному имени, до 20 результатов. Кусок имени не ищет.
- Друзей не больше 50, входящих запросов не больше 20.
- Лимит запросов — прежний, общий, через Redis. Отдельный не добавлялся.
- Жалоб нет: хранить текст игрока некому читать.

## 4. База и API

- Миграция `20261105160000_stage07_ties` только создаёт таблицу `ties`. Прежние таблицы не меняются.
- Применена на локальную базу. На прод не выкатывалась.

| Метод | Путь | Что |
| --- | --- | --- |
| GET | `/api/social` | Друзья, входящие, исходящие, блок |
| POST | `/api/social/requests` | Запрос |
| POST | `/api/social/requests/:id/accept` | Согласие |
| DELETE | `/api/social/ties/:id` | Отказ, снятие друга или своего блока |
| POST | `/api/social/block` | Блок |
| GET | `/api/social/players?name=` | Поиск по точному имени |
| GET | `/api/social/players/:id` | Визит |

Без сессии — 401. Чужая связь — 404.

## 5. Интерфейс

Страница `/social`: поиск, входящие с согласием и отказом, друзья со снятием и блоком. Ссылка «Люди» в шапке. RU/EN. Компоненты прежние.

## 6. Защита

- Сессия на каждом маршруте.
- Блок закрывает и визит, и запрос.
- Визит не содержит сохранения, почты и аватара.
- Повтор запроса возвращает прежнюю связь.
- Входящие ограничены двадцатью, друзья — пятьюдесятью.
- Общий лимит запросов Redis остался.

## 8. Не сделано

- Общие приключения и общие награды. Сохранение не рассчитано на двоих.
- Жалобы. Нет модерации.
- Присутствие онлайн и WebSocket.

## 9. Известные проблемы

- Имя есть только у вошедших через Endemion ID. Гость в поиске не виден.
- Поиск по точному имени: опечатка ничего не находит. Так задумано, чтобы не перебирать игроков.
- Блок не обрывает уже идущую жизнь: жизни и так не общие.
