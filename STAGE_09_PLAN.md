# Endemion Life — Stage 09: план

Основание: [STAGE_09_AUDIT.md](STAGE_09_AUDIT.md). Один срез: события видят дела и достижения. Новый движок не пишется.

## 1. Условия

В `Condition`:

- `deed`: id приключения и `done` — `true` для пройденного, `false` для проваленного;
- `achievement`: id достижения рода.

Оба в `checkCondition` и `describeCondition`. В конструкторах `when.deed(id)` и `when.achievement(id)`.

Событие с таким условием не приходит, пока факта нет. Это проверяет уже существующий `isEligible`, менять выбор событий не нужно.

## 2. События

Два общих, в `economy-events.ts`, рядом с событиями края:

- «Слава по дороге» — после любого пройденного дела. Исход: взять славу репутацией или оставить её краю. `maxOccurrences: 1`.
- «Род помнит» — при достижении `dynasty` (четвёртое поколение). Исход: слава рода или золото. `maxOccurrences: 1`.

Условие `deed` без id не ставлю: событие славы смотрит на список `adventure.done` целиком, через отдельное условие `deedAny`. Так одно событие работает во всех шести мирах, а не шесть копий.

Итого условия три: `deed` (конкретное дело), `deedAny` (хоть одно пройдено), `achievement`.

## 3. Дело в хронике

`regionYear` пишет `deed` для каждого приключения мира, которое завершено или провалено и ещё не в `seen`. След на напряжение остаётся только у помеченных в `ADVENTURE_MARK`: не каждое дело обязано двигать край. Хроника — обязана.

Повтор невозможен: id попадает в `seen` сразу после записи.

## 4. Что не меняется

- Выбор события, пауза, вес, отложенные последствия.
- Формат сохранения. Миграции нет.
- Дружба игроков. В событие года не входит.

## 5. Тесты

В `stage06-region.test.ts` и рядом:

- пройденное дело открывает условие, непройденное — нет;
- достижение открывает своё условие;
- событие славы не приходит без дела;
- новое приключение без строки в `ADVENTURE_MARK` всё равно пишется в хронику один раз.

## 6. Приёмка

- Событие с условием дела не приходит раньше дела.
- Последствие такого события применяется один раз.
- Хроника помнит любое приключение мира.
- Старые сохранения читаются.
