# Stage 18 — план

Не новая шкала. Порог уже есть: 75 — «самый близкий».

## Веха

Когда отношение впервые доходит до 75, в журнал человека пишется `bond`. Флаг `bond` на жизнь — один раз. Репутация +2 один раз, не за каждого близкого. Падение и новый подъём веху не повторяют.

## Событие

`common.kept-word` только при флаге. Два конца: промолчать или рассказать. Жизнь без флага идёт как раньше.

## Карточка

Подпись «Доверие», если веха была. Если общение в этом году уже было — строка «уже в этом году», не пустая панель.

## Чего не будет

Новой валюты, дружбы между жизнями, фарма репутации за каждого NPC, деплоя.
